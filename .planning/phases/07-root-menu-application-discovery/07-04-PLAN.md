<objective>
Extend `WindowManager` to accept the phase's merged `AppEntry` list at construction, group it into category buckets ready for menu rendering, provision the second (submenu) popup window's X11 resources, and generalize the existing `spawn()` double-fork pattern into an argv-based `spawnArgv()`/`launchApp()` pair that never routes `.desktop`/binary-scan-discovered entries through a shell.

Purpose: This is the presentation-layer wiring plan that later plans (Buttons.cpp submenu rendering, main.cpp startup wiring) depend on. It closes the security loop opened by DesktopEntry's Exec tokenization (Plan 07-01) at the actual process-launch site (T-7-06).

Output: `WindowManager` gains an `apps` constructor parameter, category-grouped storage, submenu window resources, and a safe launch dispatch (`spawnArgv`/`launchApp`).
</objective>
