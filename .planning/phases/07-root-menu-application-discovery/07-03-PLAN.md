<objective>
Implement `AppCache`: a hand-rolled, dependency-free JSON reader/writer for `~/.config/wm2-born-again/appcache.json` with mtime-based rescan invalidation (D-06), plus the `mergeEntries()` step that combines auto-discovered (`.desktop` + binary-scan) entries with user-authored manual entries per D-07 (default "Custom" category) and D-08 (name-based override). Extend `Config` with `menu-entry-name=`/`menu-entry-command=`/`menu-entry-category=` keys (APPS-04) so manual entries can be authored in the existing Phase 5 config file format.

Purpose: This is the third and final independent backend subsystem, and the point where all three AppEntry sources (Desktop, BinaryScan, Manual) converge into the single list `main.cpp` (Plan 07-06) will pass into `WindowManager`.

Output: `include/AppCache.h`, `src/AppCache.cpp`, extended `Config`, `tests/test_appcache.cpp`, extended `tests/test_config.cpp`, and a `test_appcache` CMake target.
</objective>
