<objective>
Wire the complete Phase 7 pipeline together in `src/main.cpp`: load config (including manual menu entries, APPS-04), load-or-rescan the app cache (APPS-01/APPS-02/APPS-03 via `DesktopEntry`+`BinaryScanner`+`AppCache`), and construct `WindowManager` with the final merged, categorized app list (APPS-05). This is the phase's final integration point and includes the mandatory manual-verification checkpoint for the root menu's visual/interactive behavior (the one behavior in this phase that RESEARCH.md and VALIDATION.md both document as having no automated coverage, consistent with the project's existing lack of screenshot-diff tooling).

Purpose: Every prior plan in this phase (07-01 through 07-05) built an isolated, unit-tested piece; this plan is the only place they are actually connected into a running binary, and the only place the full user-facing behavior can be verified.

Output: A working `wm2-born-again` binary whose root menu shows XDG-discovered and binary-scan-discovered apps, organized by category, with user config-file customizations applied, cached for fast subsequent startups.
</objective>
