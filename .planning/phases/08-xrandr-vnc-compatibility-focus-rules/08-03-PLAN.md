<objective>
Route every Shape request in the codebase through a single guarded wrapper, add the hidden env-var lever that forces the extension unavailable, and prove the rectangular fallback end-to-end against the real binary.

Purpose: today `hasShapeExtension()` guards exactly one helper while 26 raw Shape calls fire unconditionally, so on a genuinely Shape-less server the WM would issue requests the server cannot answer. One funnel gives one place to test and a greppable invariant.
Output: `Border::combineShape()`, the `WM2_FORCE_NO_SHAPE` lever, `tests/test_wm_fallbacks.cpp`, and a shape-invariant guard.
</objective>
