## Deviations from Plan

### Auto-fixed issues (each stopped its capture; fixed at source; whole capture re-run)

**1. [Rule 1 — Bug] Static analysis red at `8e29d6d`: five cppcheck findings outside the baseline**
- **Found during:** Task 2, attempt 1
- **Issue:** four `unreadVariable` (`done = true; break;` — the store is dead) in the ledger-8 modal loops (`src/Border.cpp` tab-button loop; `src/Client.cpp` move, resize, gesture) and one `shadowVariable` (`ModalWait w` shadowing the resize loop's width local). All from this closeout's own code.
- **Fix:** stores deleted, result renamed `wait`. Baseline not regenerated. Red log kept: `capture-attempts/8e29d6d-static-analysis-FAILED.log`.
- **Verification:** `static-analysis OK` on the cleaned tree before the re-capture, and in the final bundle.

**2. [Rule 1 — Bug] The window manager's own `_NET_WM_NAME` published one byte short**
- **Found during:** Task 3, attempt 1 — reading the window tree before committing it showed the check window titled `"wm2-born-agai"`
- **Issue:** `src/Manager.cpp` passed a literal length 13 for the 14-byte name. Present since the EWMH work; visible in every earlier transcript, never read.
- **Fix:** length from `std::strlen`. The `[wm_process]` supporting-window case now reads the name back as `UTF8_STRING`, byte for byte, and requires `"wm2-born-again"`: `capture-attempts/8e29d6d-red-wm-name-truncated.log` (`"wm2-born-agai" == "wm2-born-again"` fails), `8e29d6d-green-wm-name-truncated.log` (17 assertions).

**3. [Rule 1 — Bug] One new release-build warning at `2a94cbb`**
- **Found during:** reading `compiler-release.log` of attempt 2 (every gate green) — `src/Manager.cpp:434: ignoring return value of 'write' … [-Wunused-result]`, where Phase 8's release log had 0 warning lines
- **Issue:** the 08.5-11 self-pipe signal handler used `(void)write(...)`; GCC does not take a `(void)` cast as a use of a `warn_unused_result` value, and the attribute is enforced only under `-O2`, so debug and asan were silent.
- **Fix:** result bound to a named local at both self-pipe sites (`src/Manager.cpp`, `src/Events.cpp`). Release build of the window-manager target: no warning line. Log kept: `capture-attempts/2a94cbb-compiler-release.log`.
